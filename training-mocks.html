Design review · training session

A quiet ritual with live feedback, state by state.

Nine mobile frames covering every state inside a practice session, from setup to the completion bloom. Each frame is drawn in SVG inside the phone — right-click any phone and "Copy SVG" to paste into Figma as editable vectors, or screenshot the whole frame. The phone chrome (notch, status, radius) is HTML and not included in the SVG itself, so only the UI exports. Palette, type and spacing tokens are at the bottom.
